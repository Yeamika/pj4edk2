# 职责边界

pocketjsforedk2 是接口工程。参考实现与平台通过依赖消费同一份契约，按各自执行路径提供验证。

| 项目                            | 维护内容                                                                                 |
| ------------------------------- | ---------------------------------------------------------------------------------------- |
| 本工程                          | EFI ABI、生成头文件、服务 trait、输入/电源事件、配置与参数、显示设备和输出区域的数据契约 |
| `default-ui`                    | 默认 JS 页面、资源、名称卡片描述及演示预设                                               |
| 外部桌面宿主                    | 桌面宿主、设置与参数适配、演示及预览验证                                                 |
| `uefi-runtime`                  | UEFI 宿主、显示和输入适配、设置存储及启动子应用                                          |
| `crates`                        | 通用嵌入式执行层、调试消息队列、字体图集和名称卡片生成                                   |
| 平台宿主 | 固件启动、内存与 allocator、硬件驱动、持久化存储、板级启动后端、电源策略和设备验收       |

本工程不持有 PocketJS 实例，也不选择解释器、设备、像素格式或调试传输。低层显示与加速实现复用上游输出契约；这里的 `DisplayRegion`
描述黑框等逻辑输出区域。

宿主完整拥有代码、堆、运行时与回调的生命周期。跨映像使用 ABI 的不透明实例和调用入口；同一宿主内的 `BootServices::Runtime`
是关联类型。 用户上下文如何释放和重建，由实现遵守契约并验证。

默认倒计时、启动项、RIMUKS 标识、模拟电量、字体和动画属于参考页面或产品配置。`UiConfig`
与事件是页面消息契约；其校验边界不代表硬件显示模式或加速器的能力限制。

接口变化在本工程同步定义、文档与兼容说明；参考实现更新调用方并运行回归。平台固定快照保留对应来源和硬件证据，不成为另一份公共接口维护源。

调研、整理记录和设备证据保存在外部研究工作区，不纳入接口源码仓库。
