# 默认页面与共享 UI

默认页面由 `default-ui/ui.json` 列出，UEFI、WASM 预览与 DOM 参考后端消费同一套脚本。
页面只处理交互与呈现；文件访问、设备控制和 EFI 启动由宿主实现。

## 源码与接口

| 位置 | 职责 |
| --- | --- |
| [`default-ui/ui.json`](../default-ui/ui.json) | 有序脚本、原字体与字体许可证 |
| [`default-ui/pages/`](../default-ui/pages) | 菜单、设置、启动动画、Recovery、充电与低电量页面 |
| [`default-ui/src/`](../default-ui/src) | 配置、页面事件、脚本嵌入和名称卡片描述 |
| [`boot-api`](../pocketjsforedk2/crates/boot-api/src) | 公共配置、服务与数据类型 |
| [`boot-assets`](../crates/boot-assets) | 字体图集与名称卡片资源 |
| [`rendering`](../crates/rendering/README.md) | 像素对齐与纹理采样策略 |
| [`UI 包`](ui-package.md) | UEFI 与 WASM 共用的脚本、字体及烘焙图集容器 |

宿主调用 `rimuksInit(configJson)` 初始化，通过 `rimuksTick(nowMs, eventsJson)` 推进时间并传递事件。
页面使用 `bootEmit(JSON.stringify(action))` 发送动作，不直接操作硬件或磁盘。
`rimuksNameCards(configJson)` 为支持该钩子的宿主提供名称卡片描述；名称卡片通过普通图片节点旋转。
外部 UI 的输入格式见 [组件说明](../default-ui/README.md)。

## 菜单与启动

启动项由宿主提供名称、路径、图标和参数；配置了路径不代表 EFI 应用或操作系统已安装。
方向键、指针和滚轮用于选择，确认后进入启动过渡；动画结束只发送一次启动请求。
时间以宿主单调时钟为准，不把软件循环次数当作屏幕帧率。

用户输入取消当前自动启动；电源遥测不算用户输入。延时为 0 时关闭自动启动。
启动、保存和协议忙碌期间按当前页面状态阻止重复操作。
EFI 子应用返回后，宿主重新创建菜单并关闭本轮自动启动，不自动修改持久设置。

## 设置

设置支持 0–99 秒自动启动延时、数字键盘、调试开关和重新加载启动列表。
修改先保留在页面，只有宿主确认成功才更新已保存值；失败保留输入并允许重试。
重新加载启动列表由宿主扫描策略负责，页面不直接遍历 ESP。

UEFI 将延时和默认项写入选定 ESP 的双记录存储，包含 CRC、序号、flush 和读回校验；
这属于应用设置，不是持久 UEFI 变量。具体格式见 [UEFI 宿主](../uefi-runtime/README.md)。
调试开关只作用于当前会话，默认关闭，不随设置保存而开启。

## 电量与低电量保护

boot 与 recovery 显示宿主提供的电量、电压、有符号电流、外部电源及实际充电状态；未知数据明确表示未知。
可选充电按钮通过协议能力事件启用，等待回执时不重复发送。页面不持久保存充电开关，也不实现 PMIC 安全策略。

低电量页使用黑底电池和接电图形，不自动启动系统；接电后是否解除保护、何时关机由平台决定。
页面自身不访问电池寄存器。

## Recovery 与调试

Recovery 请求由宿主处理，UEFI 已提供应用会话日志、诊断和恢复启动设置实现。
恢复设置只有在写入与读回成功后才报告成功；这些操作不等于 OS recovery 或分区修复。
Web 预览使用模拟后端，不访问真实设备或分区。

PocketJSDebug 只提供显式门控的数据队列；实体连接与调试协议适配归 BSP，详见 [调试通道](debug-channel.md)。

## 字体与呈现

默认使用随仓库保留的 [Inter 字体和许可证](../default-ui/assets/README.md)。
UEFI 与 WASM 使用同一份密度感知字形图集，保留字形覆盖率；变换纹理使用最近邻采样。
DOM 后端读取原字体并使用浏览器排版，字形和边角可能不同。
默认图集覆盖可打印 ASCII；中文与字体回退需要额外接入，不能根据原字体内容推定已有完整中文支持。

## 验证范围

[历史验证](../VALIDATION.md) 对应具体版本，不等于当前代码复测结果。
Web 预览、QEMU 虚拟硬件与真实板级启动的验证范围分别记录，不能互相替代。
跨 EFI 程序共享驻留实例仍为设计。
